\# Working agreements for this repo



\## What this is

Playable housing-policy simulator. Sim core (packages/sim) is deterministic, DOM-free TypeScript.

Calibration/validation is Python in /calibration. Read docs/PLAN.md before starting any milestone.



\## Hard rules

\- packages/sim must not use Math.random, Date.now, or any global mutable state. All randomness via src/rng.ts (counter-based, hashed by seed/agentId/tick/purpose).

\- Same seed + params + policy must give identical output. Never break determinism; there is a test.

\- Do not add a dependency without a one-line justification in the commit message.

\- Every modelling change needs an ADR in docs/adr/ and an update to docs/ODD.md and docs/ASSUMPTIONS.md.

\- Every assumption is tagged DATA / LITERATURE / ASSUMED / VERIFY. Do not invent data. If unsure of a real-world number, tag it VERIFY and say so in the final message.

\- Numbers from the Bill 35 project must be checked against D:\\Tools\\Projects\\bc-str-ban-analysis before use.

\- Never describe the rent effect as "none"; say "too small to detect".

\- All art is original and generated by tools/art. No third-party sprites, fonts without an OFL/compatible licence, or copyrighted characters.



\## Workflow

\- Start each milestone in plan mode: restate acceptance criteria, list files to touch, then implement.

\- Write tests first for sim invariants. Run `pnpm lint \&\& pnpm typecheck \&\& pnpm test` before declaring anything done.

\- For UI/art: take Playwright screenshots, look at them, list defects, fix, repeat at least 3 rounds.

\- Small commits with descriptive messages. Tag each milestone (m0, m1, ...).

\- When a task is finished, report: what changed, tests run and results, what you could not verify.



\## Commands

pnpm dev | pnpm build | pnpm test | pnpm lint | pnpm typecheck | pnpm art | pnpm sim run ...
